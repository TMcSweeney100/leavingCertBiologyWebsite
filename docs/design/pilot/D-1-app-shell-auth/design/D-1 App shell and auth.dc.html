App shell and auth pages

Every page at 1140px and 390px, every state the pack spec lists. Headings, button labels, helper text and error sentences are word for word from the built components. Accent navy #1F3A6E; attention amber #A04806 is reserved for pending work and appears in D-2.

Auth pages carry no app header — they sit in the app's (auth) route group, which is what makes forced password change inescapable. They carry a quiet crest lockup instead, so a student arriving from a join code knows whose site this is. School and teacher names are the real pilot ones; student names are placeholder.

App header

On every signed-in page. Switcher nav's accessible name is “Switch role”; the current role is marked with aria-current="page".
