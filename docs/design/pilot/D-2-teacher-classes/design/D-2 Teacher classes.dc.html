Pack D-2 · teacher classes · direction 2e Navy

Teacher class pages

The one memorable thing on the class page is the join code: white mono on a navy card, sized to be read off a projector from the back of a room. Everything else stays quiet. The only other colour that interrupts is attention amber #A04806, used for pending requests and nothing else.

Subjects are a 4px colour bar down the left edge of a class row — never type, never a badge, so a subject can't be misread as a status. Later tabs (Component, Progress) are drawn greyed and unavailable.

/teach — My classes

Pending count is an amber badge on the row, and the only amber on the page.
